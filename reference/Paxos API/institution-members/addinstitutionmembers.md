---
title: Add Institution Members
excerpt: >-
  Add one or more institution members to a given institution.


  Adding new members doesn't affect existing members. For example, if an
  institution has three

  members, and adds two members using this API, then the institution would end
  up with five total members.


  For details on the properties that can be specified when creating institution
  members,

  see [Specifying Institution Members and Their
  Roles](#specifying-institution-members-and-their-roles).
