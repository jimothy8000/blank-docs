excerpt: >-
  This endpoint enables you to fetch a list of identities that you have created
  within the Paxos platform. You

  can use query parameters to filter the results returned by:

  - Summary Status of the Identity

  - Date created

  - Date updated


  Note that this endpoint supports pagination and returns a cursor token for
  fetching next pages.
