title: Get Fuel Economy Report
excerpt: >-
  Get an estimate of the potential fuel cost loss due to underiflation for a
  given location IDs.  


  This API uses vehicle fuel efficiency rating (MPG), fuel type (gasoline etc)
  and reccomended pressure retrieved at the time of the vehicle creation.

  It also uses live fuel price of the state of the location associated to the
  vehicle (limited to USA states only).


  To use Tirematics Fuel ecomnomy report API it is required to pass 2 digit
  alpha code for the state.
   
api:
  file: bridgestone.json
  operationId: getFuelEconomyReport
hidden: false
